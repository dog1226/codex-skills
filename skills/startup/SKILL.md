# 開工（startup）

## 做什麼

新對話開頭，幫主人快速回到「上次做到哪」的脈絡，不用從零解釋。

**觸發詞：** 開工、我來了、上次做到哪、我們繼續、接下來呢

## 本質：讀

**完全唯讀、無對外副作用。** 不 commit、不 push、不主動 pull、不改任何檔案。
這個技能只負責「把脈絡讀出來」，與收工（shutdown）成對：開工讀出來、收工寫進去，永不重疊。

## 動作

依序執行：

1. **讀 Obsidian 工作筆記** — 打開此專案在 Obsidian 的駕駛艙筆記，讀「上次做到哪」與「最近更動紀錄」。
2. **摘要上次進度與下一步** — 把上次的進度與預定的下一步整理成重點。
3. **git status + git fetch** — 看本地工作狀態與遠端有無更新。**只看遠端、不主動 pull**，避免任何寫入副作用。
4. **給結構化摘要等主人選方向** — 輸出結構化摘要（上次進度 / 目前狀態 / 遠端差異 / 建議的下一步選項），然後停下來等主人決定方向。

## 注意

- 全程不得有任何寫入或對外推送行為（這是與 shutdown 的關鍵分界）。
- 若找不到對應的 Obsidian 筆記，先回報，不要自行建立。
